# dx_learn
a simple game made with d3d11



## 第三方库

+ Assimp 6.0.2



## 初始化

+ 采用 cmake 管理工程
+ 构件工程：双击 build_msvc.cmd，会自动构建 vs 工程到 src/build 目录，并且会复制一份可执行文件到 bin 目录
+ 运行工程：两种方式
  1. 进入 bin 目录点击可执行文件
  2. 打开 src/build/LandingMoon.sln vs 工程，把 LandingMoon 设置为启动项目，通过 vs 执行工程



## 使用

+ 采用第三人称视角
+ 鼠标控制视角变化
+ 滚轮控制远近
+ 开始时候在地球表面上
+ 在地球上时：
  + wasd 控制飞船移动
  + 按 M 进入地球轨道，可随时进入
+ 在地球轨道上时：
  + ws 控制绕轨道移动
  + 按 E 登录地球，可随时登录
  + 按 M 进入地月轨道，可随时进入
+ 在地月轨道上时：
  + ws 控制绕轨道移动
  + 按 E 进入地球轨道，需要位移到 [地月轨道] 和 [地球轨道] 较近的位置才能进入
  + 按 M 进入月球轨道，需要位移到 [地月轨道] 和 [月球轨道] 较近的位置才能进入
+ 在月球轨道上时候：
  + ws 控制绕轨道移动
  + 按 E 进入地月轨道，可随时进入
  + 按 M 登录月球，可随时登录
+ 在月球上时：
  + wasd 控制飞船移动
  + 按  E 进入月球轨道，可随时进入
